- What it is: a live design system for native web applications, with a focus on AI interactions. It brings together foundations such as tokens and typography, components, documentation, implementation and a working registry.
- My role: I'm building and maintaining it as an independent, personal learning project.
- Why I started it: to learn what it takes to take a design system from zero to one, from foundations to implemented components and a working registry.
- How I've built it: learning from resources, testing decisions, documenting the system and updating it as I discover gaps.
- Status: live and still evolving. I keep testing, revisiting and improving it rather than treating the first version as finished.
- What I'm doing on it right now: refining its foundations, components, documentation and live registry, and exploring how a component system could become more useful to native web applications and AI-powered workflows.
- What I'm learning: the first version is only the beginning. The interesting work is testing components, revisiting decisions, discovering missing pieces and making the system more useful for both designers and developers.
- AI's role: I'm exploring how AI can support the process without treating a generated first draft as a finished design system.
- Live registry: https://system-three-rouge.vercel.app/
